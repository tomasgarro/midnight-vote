# Companion art

`cleisthenes-bust.webp` is the approved bust of Cleisthenes, the companion of
midnight.vote. It is a 640-pixel copy of
`frontend/public/images/cleisthenes.png` in the Cleisthenes repository.

| Rule | Reason |
| --- | --- |
| One figure, one face | A guide is recognised by its face. Poses come from a small badge beside the bust, not from new drawings |
| Never on a consent, eligibility or ballot screen | A friendly face beside a decision is a nudge |
| Decorative | The figure carries no information. It is hidden from screen readers |

Use `CompanionFigure` from `@/components/companion`. A pose sheet with drawn
poses replaces the badge once Tomas has approved it.
